# Evidence units

This directory contains the typed evidence units consumed by Proofbound. Each
manifest identifies an exact non-empty inventory, input closure, execution
operation, environment allowlist, and resource budget. Evidence is admitted
only through the corresponding claim manifest; the presence of a file here is
not itself a success record.

Keep model checks in `../model-checks/`, translation observations in
`../translations/`, and theorem audits here. Never add a placeholder or manual
success receipt.
